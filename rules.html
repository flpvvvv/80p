80分 - 中文版 V2.0

作者: FLP 日期: 2013年1月

简介

4人扑克牌游戏，两副牌（2x54张，有大小王之分）。两人一队，交错坐，以抢分升级为目的。 其中分数牌为：5、10 和 K，它们分别代表的分数为 5分、10分、10分，所以两副牌一共 200分。80分又称升级、双升、拖拉机、炒地皮等。

坐庄

每局都有一队在“台上”坐庄，坐庄这一队中的一人为庄家；另外一队则是在“台下”。

  • 上台条件: 台下的玩家为了“上台”坐庄，必须在一局中“抓到”80分或者80分以上，这样下一局就可以“上台”。
  • 保庄条件: 在台上的玩家为了保持坐庄和升级，必须使台下玩家抓分少于 80分。
  • 轮换规则:
    • 台下抓分 < 80分: 台上继续坐庄，但庄家轮换为同队的另一人。
    • 台下抓分 ≥ 80分: 台下成功上台，下一局庄家由此局庄家的“下家”（右手边玩家）担任。
  • 抢庄: 第一局开始时两家平等，通过“亮牌”来争抢当庄家。

升级

目的是增进友谊，其次是升级。第一局从 2 开始打。

  • 顺序: 2, 3, 4... 10, J, Q, K, A。先打过 A 的那队获胜。
  • 跳级: 默认 40分跳一级。有时规定 20分或 10分跳级。
  • 必打: 10 和 K“必打”，即跳级时不能跳过 10 和 K。

升级对照表 (标准40分跳级)

台下那队抓到的分数 庄家那队可升的级数 台下那队可升的级数
0 3 0
5~35 2 0
40~75 1 0
80~115 0 0
>=120* 0 1+

* 规则: 在 80分基础上，台下那队每多拿 40分，多升一级。
* 80~115分: 台下虽不能升级，但下局可上台。

出牌前

拿牌

  • 第一局: 最年轻者翻看一张牌决定谁先拿。按“黑红草方”逆时针规则决定（如翻到黑桃则翻牌者先拿，红桃则下家，依次类推）。
  • 流程: 逆时针依次拿牌，每人每次一张，直到剩下 8 张“底牌”结束，每人手上有 25 张牌。
  • 后续局: 由当局庄家开始拿牌。

亮牌 (抢亮)

  • 定义: 亮出庄家当前打的数字的牌。
  • 加固: 亮牌后，若又拿到一张相同的牌，可再次亮出，称为“加固”。加固影响“反”的规则。
  • 抢庄 (第一局): 亮出 2 的玩家及其对家暂时上台。若无人“反”，亮牌者成为庄家。
  • 定主: 亮牌花色即为“主花色”。
  • 无人亮牌: 若四人拿完牌均不亮牌，则进行“翻底”。

翻底

  • 规则: 一张张翻底牌，直到翻到庄家打的数字。若 8 张都不是，则以第一张翻出的花色为主花色。若翻到大小王则打“无主”。
  • 第一局翻底: 用第一张非大小王的牌决定庄家（按黑红草方规则）。
  • 注意: 一旦翻底，玩家不能再“反”。

反

  • 定义: 亮出两张相同花色的级牌（庄家打的数字）、或两张小王、或两张大王，以改变主花色、打无主或“抄底”。
  • 顺序: 方 < 草 < 红 < 黑 < 小王 < 大王。若有人已反，需用更大的牌反。
    • 若亮牌已“加固”，则不能被同花色级牌反，只能被小王或大王反。
  • 时机:
    1. 拿底前: 第一局可抢庄；非第一局仅换主花色。
    2. 埋底后: 既换主花色，又可“抄底”（拿走底牌重新埋底）。
  • 反的权力顺序: 庄家 -> 下家 -> 对家 -> 上家（逆时针）。

造反

  • 条件: 台下玩家手上分数 ≤ 15分，或有主花色情况下主牌 ≤ 3张。
  • 结果: 当局抓牌无效，重新抓牌，庄家换成台上的另一人。
  • 限制: 只有台下玩家可造反，且不能连着两局造反。

流程图

1. 第一局流程

1. 决定拿牌顺序

最年轻的人翻牌，按花色决定谁先拿牌。

2. 拿牌与定庄

情况 A: 有人亮牌
  • 大家拿满25张牌。
  • 亮牌者暂时成为庄家。
  • 若有人反: 最后反的人成为庄家。
情况 B: 无人亮牌

翻底牌来决定庄家和主花色。

3. 庄家埋底

庄家拿走8张底牌，整理手牌后，重新埋下8张底牌。

4. 抄底 (可选)

此时若有人“反”，可以拿走底牌重新埋底（可重复）。

5. 游戏开始

庄家出第一张牌。

2. 非第一局流程

1. 开始拿牌

庄家开始拿牌。

2. 定主阶段

情况 A: 有人亮牌
  • 大家拿满25张牌。
  • 若有人反: 改变主花色。
情况 B: 无人亮牌

翻底牌来决定主花色。

3. 庄家埋底

庄家拿走8张底牌，整理手牌后，重新埋下8张底牌。

4. 抄底 (可选)

此时若有人“反”，可以拿走底牌重新埋底（可重复）。

5. 游戏开始

庄家出第一张牌。

出牌阶段

牌的类别

  1. 不打无主:
    • 主牌 (36张): 大小王 (4张) + 主级牌 (8张) + 主花色其余牌 (24张)。
    • 副牌: 3个非主花色，每类 24 张。
  2. 打无主:
    • 主牌 (12张): 大小王 + 所有级牌。
    • 副牌: 4个花色均为副牌。

出牌规则

  • 流程: 逆时针出牌。首家出牌后，其他三家必须出 相同数量、相同牌型 的同类别牌。
  • 跟牌优先级: 有同类牌必须跟同类；有同牌型（如对子）必须跟牌型。
    • 例：首家出副牌对子，下家若有该副牌对子必须出对子；若无对子则出2张该副牌；若无该副牌则可垫其他牌。

牌的大小

  • 阶位: 单张 < 对子 < 拖拉机。
  • 比较: 只比首家出的牌的最高阶位。若后面玩家出的牌阶位更低，则不可能胜出。
  • 单张大小 (有主): 大王 > 小王 > 主级牌 > 副级牌 > A > K ... > 2。
  • 单张大小 (无主): 大王/小王 > 级牌。
  • 毙牌 (杀): 只有主牌可以毙副牌。若首家出副牌，其他家缺门时可用主牌毙，主牌大过任何副牌。

胜过第一位玩家

一位玩家如果手上有♥牌的对子，必须出对，如果所出的对比8对大，则自然胜过第一位玩家；还有一种胜过第一位玩家的方法是出一对主牌，无论主对的大小，都比第一位玩家出的 ♥ 8对大，但前提是这位玩家手上已经没有 ♥ 牌了（ ♥ 7不算）。要大过第一位玩家出的 ♥ 8对，有且仅有这两种方法。

“拖拉机”的定义

同一类别的牌中，大小相邻的对子。

  • 拖拉机: 两个对子。
  • 泰坦尼克: 三个对子。
  • 航母: 四个对子。

以打 ♠ 7为例：

  • ♥ 3 ♥ 3 ♥ 4 ♥ 4 是拖拉机。
  • ♦ 6 ♦ 6 ♦ 8 ♦ 8 也是拖拉机，因为 ♦ 7成为主牌后， ♦ 6和 ♦ 8大小就相邻了。
  • ♠ A ♠ A ♥ 7 ♥ 7 也是拖拉机，它俩大小相邻（注：主7紧贴A）。
  • ♥ 7 ♥ 7 ♠ 7 ♠ 7 也是拖拉机。
  • ♠ 7 ♠ 7 小王 小王 也是拖拉机。
  • 四张王 也是拖拉机。

反例：

  • ♠ 6 ♠ 6 ♠ 7 ♠ 7 不是拖拉机，因为它们大小不相邻（7是主牌，6是副牌，中间隔了好多牌）。
  • ♣ 7 ♣ 7 ♦ 7 ♦ 7 也不是拖拉机，因为它们大小相同（都是副7）。

“甩牌”的定义

在同一类别中，可以把单牌，对子和“拖拉机”混合着当成一手牌出出来，但是前提是所出的最小单牌，最小对子和最小拖拉机都比场上其他3位玩家手上拥有的此类别的牌来的大（即便其他3位玩家中有一张相同的单牌亦可甩牌，因为甩牌的玩家是首先出牌的）。

  • 甩牌失败: 罚分（每张 10分），并“强制出小”（出甩错牌中阶位最小的牌）。

结算与抠底

抠底

  • 定义: 最后一回合若台下玩家获胜，底牌分数翻倍归台下。
  • 倍数: 根据最后一回合首家出牌的牌型决定：
    • 单张: x2
    • 对子: x4
    • 拖拉机 (2对): x8
    • 每多一对翻一倍。

一钩勾到底

  • 规则: 在打 J 时，若台下用 主J 抠底成功，且总分满 80分，庄家队直接降回从 2 开始打。
  • 限制: 每次游戏每队至多被勾到底一次。
